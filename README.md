# American Honeymooner

Marketing site for American Honeymooner.

## Stack

- Single-page static site (`index.html`)
- Hosted on [Cloudflare Pages](https://pages.cloudflare.com/)
- Deployed automatically from the `main` branch

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

## Cloudflare Pages settings

| Setting | Value |
| --- | --- |
| Production branch | `main` |
| Build command | *(leave empty)* |
| Build output directory | `/` |

## Deploy

Push to `main`. Cloudflare Pages builds and publishes automatically.
